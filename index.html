06 / PERFORMANCE

Return metrics

CAGR is an approximate annualized return from net recorded cash flows and current value. XIRR is computed from dated external cash flows using an iterative estimate. Bond YTM is not yet calculated automatically; provide bond cash flows and consult a qualified source for exact yield.
